Задания.


На языке ассемблера реализовать функции и программы для их проверки.
Использовать директивы ассемблера .proc, .while, .if, ...
Указанные функции должны быть полностью независимыми (не вызывать других функций).


1. Разбивает строку str на подстроки по переданной подстроке substr.
Возвращает указатель на массив указателей (в конце нулевой указатель) на получившиеся подстроки.
Память для возвращаемого массива должна выделяться в куче.
char ** split (const char *str, const char *substr);
Пример вызова:
split ("sdfad11asdfka1222221safa1", "1") ->
[0] -> "sdfad"
[1] -> ""
[2] -> "asdfka"
[3] -> "22222"
[4] -> "safa"
[5] -> ""
[6] = NULL



2. Объединяет строки из массива str_array в одну (в порядке расположения в массиве), вставляя между ними строки из массива delim_str. Между каждой парой соседних строк из str_array вставляется очередная строка из delim_str.  Строки из delim_str берутся последовательно и (при необходимости) циклически.
Возвращает получившуюся строку.
char * join (const char **str_array, const char **delim_str)
Пример вызова
join (["abc", "bcd", "1234", "0000", "22222", "", "", "", NULL], ["AB", "CD", "", NULL]} ->
"abcABbcdCD12340000AB22222CDAB"



3. Находит в переданной строке все подстроки (длины больше 1), являющиеся палиндромами. Для каждого палиндрома подсчитать количество вхождений и для каждого вхождения запомнить индекс его начала и конца.
Возвращать из функции массив указателей на массивы, каждый из которых описывает один уникальный полиндром (и всего вхождения).
Для описания использовать только массивы 4-х байтных слов (не структуры).
Формат массива для описания одного палиндрома
[0] - указатель на строчку с палиндромом
[1] - количество вхождений
[2] - указатель на массив, описывающий вхождения, каждый элемент такого массива хранит указатель на массив из двух элементов (индекс начала и конца вхождения).
dword* find_palindromes (const char *str);
Реализовать функцию красивого вывода результата функции find_palindromes: выводить исходную строку и для каждого палиндрома под ней вертикальными стрелочками в соответсвующих позициях обозначать места начала (^) и конца (v) вхождений палиндрома.
void show_palindromes (const dword *result)
Пример вызова:
find_palindromes ("abbabb1221bbab") ->
[0] -> ["abba", 1, [[0,3],NULL]]
[1] -> ["bb", 3, [[1,2],[4,5],[10,11],NULL]]
[2] -> ["bbabb", 1, [[1,5],NULL]]
[3] -> ["bab", 2, [[2,4],[11,13],NULL]]
[4] -> ["babb1221bbab", 1, [[2,13],NULL]]
[5] -> ["abb1221bba", 1, [[3,12],NULL]]
...
Вывод:
abba:
abbabb1221bbab
^  v
bb:
abbabb1221bbab
 ^v ^v    ^v
bbabb:
abbabb1221bbab
 ^   v
bab:
abbabb1221bbab
  ^ v      ^ v
...



4. Сложения и умножения матриц (целых чисел). Входные матрицы функций задаются через двумерные динамические массивы. Возвращают статический двумерный массив (память под него выделяется в куче, исходя из рамеров входных матриц).
dword* add_matrix (dword **matrix1, dword **matrix2, dword row_count, dword col_count);
dword* mul_matrix (dword **matrix1, dword **matrix2, dword n);
Для тестирования реализовать генерацию случайных матриц и вывод результатов.




5. Функция принимает массив data элементов (типа dword) и массив handlers_array указателей (с нулевым указатем в конце) на функции обработчики. Для каждого обработчика создаётся копия массива данных и он может модифицировать элементы этой копии. Из функции возвращается массив указателей на такие модифицированные обработчиками массивы с данными. Каждый обработчик в первом аргументе принимает число элементов в переданном ему массиве данных, а следующие аргументы - последовательно указатели на все элементы массива (т.е., обработчики принимают произвольное число аргументов).
typdef void(*handler_proto)(dword count, ...);
dword** proc_array (dword *data, dword data_size, handler_proto *handlers_array) {
	res = malloc()
	for_all (p in handlers_array) {
		data_copy = malloc()
		memcpy (data_copy, data)
		p(data_size, &data_copy[0], &data_copy[1], ..., &data_copy[data_size-1])
		push_back (res, data_copy)
	}
	return res
}
Для тестирования реализовать генерацию массива случайных данных и вывод результатов.
В качестве обработчиков должны быть функции:
сортировки, поиска максимального, поиска минимального.
Кроме того нужно динамически генерировать обработчики, добавляющие к каждому элементу некоторую константу. Нужно генерировать случайные константы и для каждой из них свой обработчик (указатель на который помещать в массив). Так как константа заранее неизвестна, то нельзя написать статический код для нужной константы. Нужно придумать как генерировать для произвольной константы код динамически (память под динамическую функцию выделять с помощью VirtualAlloc/mmap).
Таким образом в массиве обработчиков будет несколько некоторое число статически обработчиков и некоторое число (динамическое) динамических обработчиков.
