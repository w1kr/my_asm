3. Дописать пример с отображением картинки и реализовать функции преобразования bmp-изображения:
1) Увеличение яркости на указанное пользователем количество процентов.
2) Псевдо-сепия: пиксель переводится в серый цвет, после чего к красному каналу добавляется немного яркости, а из синего вычитается. Пользователь определяет величину увеличения и уменьшения яркости.
3) Канальный сдвиг: значения цветовых каналов пикселя циклически меняются местами (например, красный становится зеленым, зеленый — синим, синий — красным). Пользователь определяет какой сдвиг из возможных применяется.
4) Изоляция цвета: если в пикселе преобладает выбранный цвет (больше двух других на некоторое значение), он остается прежним, остальные пиксели переводятся в оттенки серого. Пользователь определяет значение.
5) Замена цвета (хромакей): если цвет пикселя похож (с некоторым допуском) на заданный фоновый цвет, он заменяется пикселем из другого изображения. Пользователь задаёт два изображения и цвет фона.
6) Эффект тепловизора: яркость пикселя (его оттенок серого) определяет его новый цвет: темные пиксели становятся синими, средние — зелеными, яркие — красными. Придумать функцию отображения яркости на плавный градиент.
7) зеркально отразить по горизонтали;
8) зеркально отразить по главной диагонали;
Преобразования 1)-8) работают с каждым пикселем отдельно. Поэтому их необходимо реализовать через одну общую функцию, которая будет принимать в качестве параметра указатель на функцию модификации пикселя (которая вызывается для каждого пикселя). И для каждого преобразования реализовать свою функцию модификации пикселя.
В графическом интерфейсе программы должна быть возможность пользователю задавать все необходимые для преобразований параметры.
2 балла.
