
На языке ассемблера реализовать функции и программы для их проверки.
Использовать директивы ассемблера для организации функций (proc, local, ...).

1. Рекурсивное копирование директорий. Программа принимает два пути до директорий. И копирует все файлы из одной в другу. Копирование файла поблочно (без чтения всего файла в память).
void CopyFile (const char * dstFileName, const char * srcFileName);
Использовать fopen, fread, fwrite, fclose, _open, _read, _write, readdir, opendir, _mkdir или WinAPI.

2. Сортировка массива строк из файла.
Сгенерировать файл со случайными строками (разной длины).
void SortStrings (char ** stringArray)
Сформировать массив указателей на строки при чтении из файла и отсортировать его.
Использовать _open, _read, _write, _close.

3. Написать функции Map и Reduce.
Функция Map применяет переданную функцию ко всем элементам массива:
void Map (int *buf, int size, int (*funPtr) (int));
С помощью функции Map реализовать функцию, увеличивающую все элементы некоторого массива на некоторое число (т.е. передавать адрес функции, увеличивающей аргумент на это число).

typedef int (*FuncForReduceProto) (int, int);
int Reduce (FuncForReduceProto pFunc, int initValue, int *buf, size_t bufSize)
Псевдокод функции Reduce
tmp = initValue
for v in buf:
	tmp = pFunc (tmp, v)
return tmp
С помощью функции Reduce реализовать функции, подсчитывающие сумму элементов массива, максимальный и минимальный элементы.

Любое одно задание - 1 балл.
Все три задания - 2 балла.



4.Прочитать данные из файла (произвольного размера, произвольного содержимого), заменить вхождения одной последовательности байт на другую, результат записать в другой файл.
Имена файлов и последовательности (исходная и заменяемая) получать из аргументов командной строки (при необходимости, строку как-то закодировать чтобы иметь возможность передавать любые байты).
Если в тексте "adfkasddkjadfkdaqwed" заменить "ad" на "12345", то получим "12345fkasddkj12345fkdaqwed".
Условие: читать блоками по 512 байт, в памяти нельзя хранить из файла данных одновременно больше чем 1024 байт. Размер исходной последовательности не больше 512 байт. Не должно быть лишних чтений из файла и записей в файл (каждый байт читается/пишется не более одного раза).
3 балла.

Дополнительно.
Хранить в памяти из файла не более 512 байт. Размер исходной последовательности любой.
Писать в выходной файл блоками по 512 байт.
+3 балла.
